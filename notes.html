📄 Page 2: Information System (IS)

  • An information system is a way to work with information using computers and other technology. It combines different parts like computer programs, physical devices, and networks.
  • Businesses use information systems to collect important data. They use this data to run their operations smoothly.
  • Information systems also help businesses talk to their customers. Using information systems makes businesses work better than their competitors.
  • Some companies like eBay, Amazon, Alibaba, and Google are built completely on using information systems and technology to work. These companies cannot operate without using information systems.
  • Information system combines technology to help businesses work better.
  • To work well, information systems need proper data input, processing, storage, and output.
  • Companies must also set rules, audit the systems, control operations, secure equipment, and verify users.
  • When managed correctly, information systems allow businesses to effectively use data.

Examples of Information System:

  • General information systems: Provide common services that many businesses need. For example, a database system helps organize all kinds of data. A company can use data in the database to understand trends, like what products customers buy at different times.
  • Information systems are very important for businesses today. In the future, they will become even more important as more work is done by computers and AI.
  • Specialized information systems: Designed for a specific purpose in a business. Like - banking, reservation, hospitals etc.

📄 Page 3: Components of Information Systems

  • Hardware: Hardware is the physical parts you can touch like computers, disks, keyboards, and iPads. Hardware costs are lower now but using it can hurt the environment. Storage is now available in the "cloud" which you access through networks.
  • Software: Software consists of programs that run on hardware. System software like Windows helps hardware work. Application software like Excel does specific tasks. Big companies buy special software for their needs. Some software is free to use.
  • Data: Data is just facts and numbers. When put together properly, data becomes useful information for businesses to make decisions.
  • Telecommunications: Telecommunications connects computers and devices to share information. This can use wires or wireless signals like radio waves. Wires include fiber optics and cables. Wireless uses radio and microwave signals.

Information technology components and functions:

Cloud computing, Data centers, Computers, Servers, Storage, Databases, Data and data management, Operating systems, Applications, Networks, Telecommunications, Application development, Security, Websites and internet.

📄 Page 4: How Does Information System Work?

Information Systems Flow: Input ➔ Processing ➔ Output (with Storage & Feedback loop)

  • Input: First the system collects data as input. This data can come from typing, voice commands, touch screens, and sensors. The input data can be structured (organized) and unstructured (disorganized).
  • Processing: Since the input data is raw the computer's processor (CPU) has to organize it into the structured format. It does this through steps like the sorting, grouping, searching, analyzing, and making the reports.
  • Storage: Next the organized data is stored temporarily or permanently. It gets stored in databases, hard drives, or solid-state drives.
  • Output: The stored data is then analyzed and presented in a useful way like reports, dashboards, or data visualizations.
  • Feedback: Finally the system gets feedback from users on their experience. This helps measure how well the system is working.

📄 Page 5: Types of Information Systems - MIS

1. Management Information Systems: These systems integrate hardware and software to help an organization's main functions. They collect data from different systems. The data is then analyzed to help managers in Planning, make decisions for the business with the help of Reporting tools – sales, employee performance etc. For example:

MIS in a hospital may collect data on patient admissions, treatments and outcomes to help administrators make decisions about resource allocation like – allotment of Doctor, room, list of essential tests and it helps in automating the process.

  • Purpose: Provides summarized reports from the data collected by TPS for middle level management to support decision-making.
  • Users: Middle managers
  • Examples: Sales management systems, Budgeting systems, Inventory control reports
  • Features: Periodic reports (daily, weekly, monthly), Summarized data, Supports structured decisions

📄 Page 6: Decision Support Systems (DSS)

2. Decision Support Systems (DSS): These systems help organizations make informed decisions. They analyze rapidly changing information that cannot be planned in advance. Decision support systems can work automatically or with human operators. Using both humans and computers together works best. For example, a retail chain may use a DSS to collect and analyze data on customer demographics, buying behavior and sales performance in order to guide changes in inventory management and marketing campaigns. A DSS is also known as a business intelligence (BI) system.

  • Purpose: Helps managers make semi-structured or unstructured decisions using data, models, and analytical tools.
  • Users: Senior managers, analysts
  • Examples: Risk analysis tools, Financial planning systems, Simulation models
  • Features: Interactive and flexible, Uses data from TPS, MIS, and external sources, Supports "what-if" analysis

📄 Page 7: Transaction Processing System (TPS)

3. Transaction processing system (TPS): A TPS processes transactional data and generates useful insights to help streamline transactional processes.

  • Purpose: Handles day-to-day business transactions and operations.
  • Users: Operational staff, clerks, supervisors.
  • Examples: Sales order entry, Payroll systems, Inventory management, ATM transactions
  • Features: High volume of data, Accuracy and speed are critical, Real-time or batch processing

📄 Page 8: Customer Relationship Management (CRM)

A CRM platform is a comprehensive tool or set of tools that enables organizations to view customer information in real time and use that information to guide their sales, marketing, support, commerce and other decisions.

The effectiveness of any enterprise IS depends on whether it aligns with the organization's information requirements, as well as its business goals, usability and features related to information security and regulatory compliance.

  • Purpose: Manages a company's interactions with current and potential customers.
  • Users: Sales, marketing, customer service teams
  • Examples: Salesforce, Zoho CRM, HubSpot
  • Features: Tracks customer interactions, Manages sales pipeline, Helps with targeted marketing

📄 Page 9: Knowledge Work System (KWS)

5. Knowledge work system (KWS): These systems provide useful insights for knowledge workers, such as researchers, analysts and consultants.

For example, marketing analysts may use a KWS to analyze customer data and track the performance of marketing campaigns.

  • Purpose: Simulates human decision-making by applying expert-level knowledge to solve specific problems.
  • Users: Specialists and professionals
  • Examples: Medical diagnosis systems, Credit approval systems, Troubleshooting tech support
  • Features: Knowledge base + inference engine, Uses rules ("if-then" logic), Can explain reasoning behind conclusions

📄 Page 10: Supply Chain Management (SCM)

6. Supply Chain Management (SCM): Supply Chain Management (SCM) is the process of managing the flow of goods, services, information, and finances from suppliers to customers.

It involves activities like procurement, production, inventory, transportation, and distribution to ensure products reach the right place at the right time, efficiently and cost-effectively.

  • Purpose: Manages flow of goods, services, and information across the supply chain.
  • Users: Logistics, operations, and procurement teams
  • Examples: Order tracking systems, Inventory forecasting tools, Supplier relationship management
  • Features: Real-time inventory tracking, Demand planning, Streamlines procurement and delivery

📄 Page 11: Managing Information Systems

To effectively manage and maintain an IS, IS professionals must understand the system's capabilities and be aware of the needs and requirements of the businesses and users that rely on it. They must also understand the following aspects:

  • Security: As with any technology-enabled or internet-connected system, information systems are also vulnerable to cyberthreats, like hacking, viruses, malware and unauthorized access.
  • Security Measures: This is why IS administrators must make an effort to boost IS system and data security. They can do this by implementing extensive security tools and measures, like access control, firewalls, intrusion detection systems, intrusion prevention systems, antivirus and data encryption.
  • Patches & Audits: It's also crucial to apply security patches and updates as they become available to fix vulnerabilities and prevent their exploitation by threat actors. Additionally, regular security audits, vulnerability assessments and penetration testing can reveal potential security risks before they can result in damaging attacks or data breaches.
  • Data management: Proactive and ongoing data management is needed to maintain the accuracy, consistency and integrity of the data stored in the IS. IS administrators must implement data backup processes to prevent data loss in case of system failures or disasters. Admins must also ensure that data is stored in a structured and organized manner so that it can be easily accessed and analyzed as needed.
  • Network management: IS administrators must implement systematic network management processes to monitor and maintain the IS network infrastructure. They must ensure that network devices -- routers, switches, servers, etc. -- are correctly configured, network traffic is managed properly to avoid congestion and delays, and network security measures, like firewalls, to block malicious traffic and prevent unauthorized access are implemented and maintained.
  • System updates and upgrades: IS administrators must regularly update and upgrade the IS and implement a patch management process to ensure that all components in the IS continue to run smoothly. They must also monitor system performance metrics, such as CPU and memory usage, to identify and troubleshoot performance issues as early as possible.

📄 Page 12: User Support & IS Pyramid

  • User support: IS administrators must provide the necessary training and job-appropriate data so users can use the system effectively. Help desk support is also useful in assisting users with troubleshooting problems. Easy access to a knowledge base with articles, FAQs and chatbots can also help resolve user queries without overburdening the help desk team.

Information Systems Pyramid Layers:

  • Management Support (Top): Executive information systems, Decision support systems, Management reporting systems.
  • Support of Knowledge Work (Middle): Professional support systems, Collaboration systems, Knowledge management systems.
  • Operational Support (Bottom): Supply chain management, Customer relationship management, Transaction processing systems.

📄 Page 13: Solving Business Problems with Information Systems

Information Systems (IS) are powerful tools for solving business problems because they help organizations collect, process, analyze, and act on data to make better decisions, improve efficiency, and gain a competitive edge.

How Information Systems Solve Business Problems:

  1. Improving Decision Making: IS provide real-time data and analytics that help managers and staff make better, faster decisions.
    Example: A sales dashboard shows real-time performance by region. Managers can see which areas are underperforming and adjust their strategy.
  2. Automating Routine Tasks: By automating repetitive processes, IS save time and reduce human error.
    Example: An HR system can automatically calculate payroll, track leave, and handle recruitment—freeing HR staff to focus on strategic work.
  3. Enhancing Customer Experience: IS help businesses deliver better, faster, and more personalized service to customers.
    Example: CRM (Customer Relationship Management) systems track customer preferences and purchase history, allowing targeted promotions and personalized support.
  4. Improving Communication and Collaboration: IS support smooth internal communication and collaboration, especially in distributed or remote teams.
    Example: Project management tools like Asana or Microsoft Teams help teams track progress, assign tasks, and share updates in one place.
  5. Streamlining Supply Chain and Operations: Information systems track inventory, suppliers, shipping, and demand, allowing businesses to optimize their supply chain.
    Example: A Supply Chain Management (SCM) system can detect delays and automatically adjust production schedules.

📄 Page 14: Strategic Planning & Amazon Case Study

  1. Supporting Strategic Planning: With historical data and predictive analytics, IS help businesses plan for the future.
    Example: A Business Intelligence (BI) tool analyzes sales trends to help a retailer decide what products to stock next season.

Characteristics of an Effective Information System:

  • Speed: Processes are completed quickly.
  • Resource Optimization: Uses minimal computing power or manual labor.
  • Cost-Effectiveness: Reduces expenses like paper use, staff hours, or IT infrastructure.
  • Automation: Replaces repetitive human tasks with software processes.
  • Relevance: The system provides information that users actually need.
  • Timeliness: The information is available when it's needed.

  • Step 2: Analyze the Data: Cappuccinos are selling well every morning. Croissants are barely selling, but the shop buys 20 each day. Afternoon sales are low across all items.

In the context of information systems, effectiveness focuses on achieving desired outcomes and meeting strategic goals, while efficiency emphasizes the use of resources and time to achieve those goals with minimal waste. Effectiveness is about "doing the right things," while efficiency is about "doing things right."

Effectiveness Criteria:

  • Meeting Strategic Goals: Information systems should contribute to the overall strategic objectives of the organization.
  • Achieving Desired Outcomes: The system should help users accomplish their tasks and goals effectively.
  • Data Quality and Accuracy: Reliable and accurate data is crucial for effective decision-making and operations.
  • User Satisfaction: Users should be satisfied with the system's functionality, ease of use, and responsiveness.
  • Return on Investment (ROI): The system should provide a positive return on the investment made in its development and implementation.
  • Data Integrity and Security: Data should be protected from unauthorized access and breaches.

Efficiency Criteria:

  • Cost-Effectiveness: The system should minimize costs associated with development, maintenance, and operation.
  • Resource Utilization: The system should optimize the use of resources (time, personnel, hardware, software).
  • Speed and Response Time: The system should provide information and perform tasks quickly and efficiently.
  • Data Transfer Speed: How quickly and reliably data can be transmitted across the network is a crucial efficiency factor.
  • Reduced Training Time: An IS that is easy to learn and use saves time and resources on training personnel.
  • Automation: Automating repetitive tasks reduces manual effort and frees up users for more strategic work.
  • Scalability: The system should be able to accommodate increasing user demands and data volumes without significant disruption.
  • Manageability: The system should be easy to monitor, maintain, and manage.
  • Reliability: The system should be reliable and consistently available.
  • Interoperability: The system should be able to integrate with other systems and technologies.
  • Minimizing Waste: Efficient systems avoid unnecessary resource consumption, reducing costs and improving overall performance.

Efficiency criteria in information systems (IS) focus on optimizing resource utilization to achieve desired outcomes with minimal waste. This includes factors like hardware performance, network efficiency, and data storage efficiency. In essence, it's about maximizing output with the least input.
